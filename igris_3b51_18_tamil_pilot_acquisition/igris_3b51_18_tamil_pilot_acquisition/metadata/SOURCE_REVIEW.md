# Tamil pilot source review

- Source: AI4Bharat IndicCorp V2
- Dataset card: https://huggingface.co/datasets/ai4bharat/IndicCorpV2
- Dataset card states datasets created as part of the work are CC0.
- Tamil file listed at `data/ta.txt` is approximately 11.8 GB; this kit uses the Hugging Face dataset-viewer rows API instead of downloading that full file.
- Config/split used by the script: `indiccorp_v2` / `tam_Taml` (from the repository's dataset configuration).
- Sampling method: first 10,000 available rows. This is not random or representative.
- Commercial-use gate: retain provenance, inspect sample quality and source composition, and review underlying web-content rights before final commercial approval.
